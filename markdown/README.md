# 🛠️ Promptimity AI Skills Reference

Welcome to the **Promptimity AI Skills Reference Guide**! This directory contains individual markdown documentation files for all the curated AI skills available to enhance your learning, writing, and development workflows.

> [!NOTE]
> **Skills** are specialized instruction sets that teach your AI assistant how to handle specific tasks. You can trigger any of these by typing `@` followed by the skill name in your AI chat (e.g., `@brainstorming`).

## 💡 How to Use These Skills

To trigger any of these skills in a supported AI chat:
1. Open your AI chat interface.
2. Type `@` followed immediately by the skill trigger (e.g. `@react-best-practices`).
3. Add your prompt or describe what you want to accomplish.

> [!TIP]
> **Example Prompt:**
> `@react-best-practices explain the best way to handle state management with Next.js App Router for a multi-step checkout form.`
