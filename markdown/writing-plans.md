# 📈 @writing-plans

## 📌 Overview
- **Trigger**: `@writing-plans`
- **Category**: General Productivity & Workflow (For Both)
- **Purpose**: Outline clear, step-by-step technical implementation plans before beginning a complex homework assignment, feature build, or system migration.
- **Best For**: Getting structured, stress-free roadmaps that eliminate ambiguity and prevent missed requirements.

---

## 🚀 How to Trigger
In your Promptimity AI chat, type:
```text
@writing-plans [describe the project, feature, or assignment you need to build]
```

---

## 💡 Key Capabilities & Features

- **Phased Roadmap Design**: Breaks down massive tasks into logical phases (e.g. Phase 1: Setup & Data Schemas, Phase 2: Core Components, Phase 3: APIs, Phase 4: Verification).
- **Dependency Tracking**: Highlights what files or systems must be built first before other modules can begin, avoiding redundant development loops.
- **Open Questions & Assumption Locks**: Proactively flags underspecified details, structural ambiguities, or edge cases to align on before work starts.
- **Verification Milestones**: Defines clear, actionable ways to test and verify the correctness of each completed phase.
- **Modular File-by-File Outlines**: Lists exactly which files will be modified, created, or deleted with clear summaries.

### Example 2: Plan for Complex Class Assignment
**Prompt:**
> `@writing-plans I have a university computer science assignment to build a simple compiler in Python. Let's write a phase-gated implementation plan to handle the lexical analyzer, parser, AST generation, and final tests.`

---

## 📘 Best Practices
1. **Never Start Without a Plan**: For complex tasks, spending 10 minutes writing an implementation plan saves hours of debugging and rewriting.
2. **Flag Edge Cases Early**: Identify performance bottlenecks, data scaling limits, or security concerns during the planning phase rather than during testing.
3. **Establish Verification Steps**: Write down exactly how you will prove a step works before moving to the next.
